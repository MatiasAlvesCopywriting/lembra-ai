# ⏰ Lembra Aí - Lembretes e Alarme

**Nunca mais esqueça um compromisso importante.**

O Lembra Aí nasceu de uma necessidade simples: eu e alguns parentes não conseguíamos nos lembrar de compromissos (exames, mecânico etc.) sem muitos post-its colados na cozinha. A minha memória falhava, e o alarme comum do celular não foi pensado para mostrar a data do compromisso, o horário, ou o que você deve levar. Aqui é diferente: **o aviso toca como um alarme de verdade, em tela cheia, mesmo com o celular bloqueado.** E ele não avisa só uma vez: avisa com antecedência, para dar tempo de se preparar.

## ✨ Funcionalidades

- 📅 **Crie eventos** com nome, data, horário e descrição
- 🔔 **5 avisos por evento:** 30 dias, 7 dias, 1 dia e 3 horas antes, e também na hora
- 📱 **Alarme em tela cheia**, mesmo com a tela bloqueada
- ✏️ **Edite** ou 🗑️ **exclua** eventos quando quiser
- 🕓 Eventos que já passaram ficam marcados em cinza
- 🚀 **Atualização automática:** o app avisa quando sai uma versão nova e instala com um toque

## 📥 Como instalar

> O Lembra Aí ainda não está na Play Store. A instalação é feita pelo arquivo APK.

1. Pelo celular, abra a página da versão mais recente:
   👉 **[Baixar o Lembra Aí](https://github.com/MatiasAlvesCopywriting/lembra-ai/releases/latest)**
2. Em **Assets**, toque no arquivo que termina em **`.apk`** para baixar.
3. Abra o arquivo baixado.
4. Se o Android pedir, autorize **"Instalar apps desconhecidos"** para o navegador ou para o gerenciador de arquivos.
5. Toque em **Instalar** e pronto! 🎉

> ⚠️ Se aparecer um aviso do **Play Protect**, toque em **"Mais detalhes" → "Instalar assim mesmo"**. Esse aviso aparece porque o app não veio da Play Store, e não significa que ele faça mal ao celular. O código está todo aberto aqui no repositório para quem quiser conferir.

## 🔐 Permissões e por que elas existem

O app só pede o necessário para o alarme funcionar. As permissões são pedidas **depois que você cria o primeiro evento**, com uma explicação antes de cada pedido.

| Permissão | Para que serve |
|---|---|
| 🔔 **Notificações** | Mostrar os avisos dos seus eventos |
| 📱 **Notificações em tela cheia** | Fazer o alarme aparecer na tela mesmo com o celular bloqueado |
| ⏰ **Alarmes exatos** | Tocar no minuto certo, sem atraso |
| 🌐 **Internet** | Verificar e baixar novas versões do app |
| 📦 **Instalar apps desconhecidos** | Instalar as atualizações baixadas pelo próprio app |

🔒 **Seus eventos ficam salvos só no seu celular.** Nada é enviado para servidores.
